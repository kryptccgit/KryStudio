# Wave 12.2b: finish parity and close the gaps (written 2026-10-14)

Follows Wave 12.2 (`research/16-ableton-parity.md`, done). This wave closes:
- what 12.2 left open: comping, grid LEDs, automating knobs inside racks, instrument-rack latency;
- the hardware item from 12.3: MIDI clock;
- the first scripted devices (the Max for Live answer);
- the gaps the guide writers reported:
  - the Krypt Analyzer window draws nothing;
  - no EQ curve or gain-reduction meters;
  - no time-signature UI;
  - Krypt TriOsc has no LFO;
  - Follow tempo isn't enabled on dropped loops;
  - markers can't be renamed;
  - no clip-fade UI;
  - no user templates.

**Rule:** every capability is also an MCP tool or an argument on one, and every mutation is a `shared/commands` command.

## 2. Each agent owns its own contract

There is no lead-written contract this time; the areas barely overlap.
- New types go in your own new files (`shared/schema/takes.ts`, `shared/scripts/*`, …).

- Protocol changes go in `shared/engine/protocol.ts` + Rust `protocol.rs` / `control.rs` / `telemetry.rs` + `docs/ENGINE_PROTOCOL.md` (a new section per agent: takes §13, hardware §14, meters §15, rack-plus extends §12).

## 4. Rules for every agent

- Read `CLAUDE.md` (and `../kryptguidelines.md` for UI) first.
- **Hard rules:**
  - MIT-compatible dependencies only. Check the licence before adding any. Run `node scripts/license-check.mjs` if you add an npm or cargo dependency.
  - No GPL code or ports.
  - No Ableton or FL trade dress or names.
  - No silent failures (toasts, `{ok, message}`).
  - Krypt UI kit: Chakra Petch, `bg-krypt-void`, `border-white/10`, lucide icons, gradient as accent only.
  - Every mutation goes through a command.
- **Never** run `npm run build`, `npm run engine:build`, `npm run dist` or `npm run dev`. The user's app and MCP shims may be running.
  - Rust: only with your own `CARGO_TARGET_DIR` (§1), from the repo root.
  - Never kill processes.
- You cannot run the app. The lead takes screenshots later, so write pure logic in testable modules.
- Before you finish, run `npm run typecheck && npm test`, and your crate's tests (Rust). A failure in another agent's file is reported, not fixed.
- **Report** (under 450 words):
  - what you built;
  - the exact test counts;
  - contract additions (protocol / schema / API);
  - what the lead must check or click;
  - anything untested.
