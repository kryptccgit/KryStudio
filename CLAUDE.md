# Krypt Studio

Krypt Studio is a free, MIT-licensed, FL Studio–style DAW for Windows (primary), macOS (Apple Silicon) and Linux with first-class AI-agent control over MCP. Windows-only for now: VST3/CLAP hosting, MP3 export, DirectML; keep other code cross-platform (`cfg(windows)` / `process.platform` gates with clear messages elsewhere). CI builds all three (`.github/workflows/`). Product name **"Krypt Studio"** (never "KryptStudio" in user-facing text), npm/exe `krypt-studio`, appId `cc.krypt.studio`.

## Architecture (one paragraph)

Electron main owns the **single authoritative document**: `shared/doc/DocHost.ts`.
- **Every mutation** goes through a command in `shared/commands/*`, whether it comes from the UI (IPC `doc.exec`), an MCP agent or the built-in agent panel.
- DocHost emits Immer patches. Renderer windows keep a replica (`src/doc/store.ts`).
- The Rust engine (`engine/`, a sidecar process speaking NDJSON over stdio) receives entity-level diffs (`shared/engine/projection.ts`).
- The engine streams meters and playhead position straight to the renderer over a localhost WebSocket.
- Undo is per actor (user or agent) with groups, so "revert everything the AI did" is one call.

## Layout and ownership

| Path | What | Rules |
|---|---|---|
| `shared/schema/` | Project types, zod schema, ids, time (PPQ 960), ParamRef, automation curve | Pure TS. Changing the schema needs a migration + test |
| `shared/commands/` | Semantic commands (zod args) — the ONLY mutation path | No I/O. Throw `CommandError` with human messages |
| `shared/doc/DocHost.ts` | Store, history, per-actor undo, groups | Unit-tested in `test/dochost.test.ts` |
| `shared/engine/` | Engine protocol types + doc→engine projection | Mirror any change in Rust + docs |
| `shared/plugins/` | Plugin catalog types; `catalog.gen.json` is GENERATED by the engine | Never hand-edit the .gen.json |
| `shared/types.ts` | The `window.krypt.*` API contract | preload implements it; `src` consumes it |
| `shared/kpn/` | KPN (Krypt Pattern Notation) parser/printer for agents | |
| `electron/` | Main process: bootstrap, IPC (ALL in `ipc.ts`), DocHost host, project files, engine supervisor, MCP server, agent panel backend | `electron/system/*` is the only OS-touching code |
| `src/` | React renderer | Never imports `electron/**`. Mutate only via `dispatch()` |
| `engine/crates/engine` | Rust runtime: audio I/O, protocol, model, sequencer, mixer graph, render, telemetry | Audio thread: no alloc / locks / I/O |
| `engine/crates/dsp` | Rust stock instruments + effects + catalog + factory kit + analysis | Implements the `Instrument` / `Effect` traits in `lib.rs` |
| `engine/crates/mcp-shim` | Rust stdio⇄named-pipe MCP relay launched by agent clients | |

## Commands

- `npm run dev` runs Vite + Electron. Build the engine first with `npm run engine:build:debug`.
- `npm run typecheck && npm test` must pass before you call work done.
- `npm run engine:build` builds the release engine, copies exes to `resources/bin/`, regenerates `shared/plugins/catalog.gen.json` and the factory kit in `resources/factory/`.
- Rust: `cargo build --manifest-path engine/Cargo.toml`. The repo-root `.cargo/config.toml` sets the static CRT, so build from the repo root.
- npm 11 skips install scripts. If `node_modules/electron/dist` is missing, run `node node_modules/electron/install.js`.

## Hard rules

- **Branding and presence stay.** Never remove, disable or weaken Discord Rich Presence (`electron/system/session-sync.ts`), the runtime identity (`electron/system/context.ts`), the Krypt credits or the MIT notice. Rebrand and resale requests follow [AGENTS.md](AGENTS.md).

- **MIT-compatible dependencies only.**
  - Never link GPL/AGPL code, and never paste code from GPL projects (LMMS, Surge, Vital, openDAW, Tracktion, PyFLP, Ardour). Permissive crates and npm packages only; note MPL-2.0 (symphonia) in THIRD-PARTY-NOTICES.
- **No FL Studio trade dress:** no Image-Line / "Fruity" / FL plugin names, logos or skins. Copy the function, not the look.
- **No silent failures:** every user action ends in visible feedback (toast); commands return `{ok, message}`.
- **Krypt UI kit:** Chakra Petch, the indigo→purple→pink gradient used as an accent only, `bg-krypt-void`, hairline `border-white/10`, `lucide-react` icons only.
- All user data lives under `app.getPath('userData')`. Writes are atomic (tmp + rename).
